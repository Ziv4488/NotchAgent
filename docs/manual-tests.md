# 手动测试清单

自动化测试覆盖不到的部分：窗口层级、屏幕几何变化、焦点归属、跨 Space 行为。
每次动到 `NotchWindow` / `NotchHostingView` / `IslandWindowController` 都要过一遍。

跑之前先起 app：

```sh
xcodebuild -project NotchAgent/NotchAgent.xcodeproj -scheme NotchAgent -configuration Debug build
open ~/Library/Developer/Xcode/DerivedData/NotchAgent-*/Build/Products/Debug/NotchAgent.app
```

想直接开在某个形态：`--args -debugState running|notice|expanded|newtask`。
其余状态跃迁走**菜单栏图标**里的调试菜单。

> 菜单栏图标长得像一个刘海矩形，在你那排状态图标的**最左边**。
> 注意：第三方状态项在 `CGWindowListCopyWindowInfo` 里由「控制中心」统一合成、
> 报成匿名的 `Item-0`，所以别靠窗口列表找它——要开关 app 数个数。

## 1. 窗口层级与命中

岛的画布固定是最大态尺寸（576×430 的透明窗口，压在屏幕顶部中央）。
岛本身只占其中一小块，**其余全是透明区**。命中测试必须收回到岛的轮廓里。

| # | 操作 | 期望 |
|---|---|---|
| 1.1 | 看 idle 态 | 岛就是刘海本身：上沿两侧内凹拐角、底部圆角，除了极淡阴影看不出多余东西 |
| 1.2 | **idle 态下**，点岛正下方的桌面／窗口（大约屏幕正中偏上那片） | 点击**穿透**，落到下面的 app 上。这块是透明画布，绝不能吞点击 |
| 1.3 | **idle 态下**，点菜单栏最左边的「NotchAgent / 文件」等菜单 | 菜单正常打开。岛只有 193pt 宽，盖不到那里 |
| 1.4 | 展开态下点菜单栏 | 岛此时 560pt 宽，**会**盖住中间那段菜单栏，这是设计如此。只要没被盖住的部分能点就算过 |
| 1.5 | 点控制中心 / 时钟 | 正常展开 |
| 1.6 | 悬停在岛上 | 只有轻微提亮，**不展开、不预览** |

## 2. 焦点（spec 11.2 的四个条件）

| # | 操作 | 期望 |
|---|---|---|
| 2.1 | 在别的 app 里打字，然后点岛展开 | 岛拿到焦点、**输入框光标直接就位**，不用再点一下；前一个 app 失焦（和 Spotlight 一样） |
| 2.2 | 在展开的岛里打字 | 字进输入框 |
| 2.3 | 切中文输入法打字 | 候选框浮在岛**之上**，不被挡 |
| 2.4 | 按 Esc | 新建流程中先取消新建；再按一次收起岛，焦点回到 2.1 里那个 app |
| 2.5 | idle / running / notice 三态 | 全程不抢焦点，别的 app 打字不受影响 |

## 3. 屏幕几何

| # | 操作 | 期望 |
|---|---|---|
| 3.1 | 插上外接显示器 | 岛留在内置屏（主屏）上，不复制到外接屏 |
| 3.2 | 把菜单栏拖到外接屏（外接屏成主屏） | 岛跟过去，无刘海所以内凹拐角为 0，呈屏幕顶部居中浮条 |
| 3.3 | 拔掉外接屏 | 岛回内置屏，内凹拐角恢复 |
| 3.4 | 改分辨率（缩放档位） | 岛重新测量，宽高跟着变，仍贴齐上沿 |
| 3.5 | 合盖睡眠再唤醒 | 岛还在且位置正确 |

## 4. Space 与全屏

进出全屏有约一秒动画，通知到达时窗口尺寸还没稳定。藏起来之后会每 0.7 秒轮询一次，
所以「该回来的时候没回来」最多等一秒，**超过就是 bug**。

| # | 操作 | 期望 |
|---|---|---|
| 4.1 | 切到另一个 Space | 岛跟随，每个 Space 都在 |
| 4.2 | 把某个 app 切全屏 | 岛消失（刘海区被系统占用，spec 3.4）。**只有全屏才消失**，普通最大化不算 |
| 4.3 | 退出全屏 | 岛在一秒内自己回来，不需要点任何地方 |
| 4.4 | 全屏 app 与普通 Space 之间来回切 | 岛跟着消失/恢复，不残留 |

## 5. 四态与动画

| # | 操作 | 期望 |
|---|---|---|
| 5.0 | 一个会话都没有时点开岛 | 直接落在新建流程：项目列表（读 `~/.claude/projects/`）+ 指令框，光标就位 |
| 5.1 | 选一个项目、敲指令回车 | 生成一个新 tab（第 1 阶段是假会话），岛进入 running |
| 5.2 | 点 tab 条末尾的 ＋ | 回到新建流程 |
| 5.3 | 调试菜单「新建假会话」两次 | 仍是 running，状态带显示选中的那个 |
| 5.4 | 「完成最早的会话」 | → notice，弹出 tab 条，完成的 tab 图标带绿色对勾角标 |
| 5.5 | 不动它 | notice **常驻**，不自动收起 |
| 5.6 | 再「完成最早的会话」 | 仍是 notice，两个 tab 都带对勾 |
| 5.7 | 点 notice 上的某个 tab | → expanded，该 tab 的对勾消失 |
| 5.8 | 点 ✕ 收起，此时还有别的未读 | 回落到 notice，不是 idle |
| 5.9 | 「全部已读」后收起 | 有任务在跑就回 running，都没有就回 idle |
| 5.10 | 展开状态下触发「完成最早的会话」 | **不打断展开** |
| 5.11 | 展开后去点别的 app | 岛**保持展开**。这是刻意的：要能从访达把文件夹拖进岛，一点别处就收起会让拖拽没法完成。只有 ✕ 和 Esc 收起 |
| 5.12 | 四态之间来回切 | 宽、高、圆角同时插值，内凹拐角全程与主体连续、无缝隙毛边 |

## 6. 对照视觉定稿
