# 手动测试清单

自动化测试覆盖不到的部分：窗口层级、屏幕几何变化、焦点归属、跨 Space 行为。
每次动到 `NotchWindow` / `IslandWindowController` 都要过一遍。

跑之前先起 app：

```sh
xcodebuild -project NotchAgent/NotchAgent.xcodeproj -scheme NotchAgent -configuration Debug build
open ~/Library/Developer/Xcode/DerivedData/NotchAgent-*/Build/Products/Debug/NotchAgent.app
```

想直接开在某个形态：`--args -debugState running|notice|expanded`。
其余状态跃迁走菜单栏图标里的调试菜单。

---

## 1. 窗口层级与命中

| # | 操作 | 期望 |
|---|---|---|
| 1.1 | 看 idle 态 | 岛就是刘海本身：上沿两侧内凹拐角、底部圆角，除了极淡阴影看不出多余东西 |
| 1.2 | 展开后点岛外的桌面 | 岛收起，点击**穿透**到桌面。岛的画布是最大态尺寸（576×430），透明区域绝不能吞点击 |
| 1.3 | 展开态下点菜单栏「文件」等菜单 | 菜单正常打开，说明透明区不挡事 |
| 1.4 | 点控制中心 / 时钟 | 正常展开。控制中心层级 25，岛是 26，岛会盖在它上面，但不应挡住点击 |
| 1.5 | 悬停在岛上 | 只有轻微提亮，**不展开、不预览** |

## 2. 焦点（spec 11.2 的四个条件）

| # | 操作 | 期望 |
|---|---|---|
| 2.1 | 在别的 app 里打字，然后点岛展开 | 岛拿到焦点，前一个 app 失焦（和 Spotlight 一样） |
| 2.2 | 在展开的岛里打字 | 字进输入框 |
| 2.3 | 切中文输入法打字 | 候选框浮在岛**之上**，不被挡 |
| 2.4 | 按 Esc | 岛收起，焦点回到 2.1 里那个 app |
| 2.5 | idle / running / notice 三态 | 全程不抢焦点，别的 app 打字不受影响 |

## 3. 屏幕几何

| # | 操作 | 期望 |
|---|---|---|
| 3.1 | 插上外接显示器 | 岛留在内置屏（主屏）上，不复制到外接屏 |
| 3.2 | 把菜单栏拖到外接屏（外接屏成主屏） | 岛跟过去，无刘海所以内凹拐角为 0，呈屏幕顶部居中浮条 |
| 3.3 | 拔掉外接屏 | 岛回内置屏，内凹拐角恢复 |
| 3.4 | 改分辨率（缩放档位） | 岛重新测量，宽高跟着变，仍贴齐上沿 |
| 3.5 | 合盖睡眠再唤醒 | 岛还在且位置正确 |

## 4. Space 与全屏

| # | 操作 | 期望 |
|---|---|---|
| 4.1 | 切到另一个 Space | 岛跟随，每个 Space 都在 |
| 4.2 | 把某个 app 切全屏 | 岛**消失**（刘海区被系统占用，spec 3.4） |
| 4.3 | 退出全屏 | 岛恢复 |
| 4.4 | 全屏 app 与普通 Space 之间来回切 | 岛跟着消失/恢复，不残留 |

## 5. 四态与动画

| # | 操作 | 期望 |
|---|---|---|
| 5.1 | 调试菜单「新建会话」 | idle → running，横向展开，spring 动画不抖 |
| 5.2 | 再「新建会话」两次 | 仍是 running，状态带显示选中的那个 |
| 5.3 | 「完成最早的会话」 | → notice，弹出 tab 条，完成的 tab 图标带绿色对勾 |
| 5.4 | 不动它 | notice **常驻**，不自动收起 |
| 5.5 | 再「完成最早的会话」 | 仍是 notice，两个 tab 都带对勾 |
| 5.6 | 点 notice 上的某个 tab | → expanded，该 tab 的对勾消失 |
| 5.7 | 点 ✕ 收起，此时还有别的未读 | 回落到 notice，不是 idle |
| 5.8 | 「全部已读」后收起 | 有任务在跑就回 running，都没有就回 idle |
| 5.9 | 展开状态下触发「完成最早的会话」 | **不打断展开** |
| 5.10 | 四态之间来回切 | 宽、高、圆角同时插值，内凹拐角全程与主体连续、无缝隙毛边 |

## 6. 对照视觉定稿

把 `.superpowers/brainstorm/*/content/states-v2.html` 在浏览器里打开，逐态比对：
间距、字号、圆角、状态点颜色、tab 选中态的底色与顶部高光。
